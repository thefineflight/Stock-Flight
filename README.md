# StockFlight

A Streamlit-based stock technical analysis dashboard for potential trade setups.

## 🚀 Live App

**[Open StockFlight](https://stockflight.streamlit.app/)**

## 📊 Features

* Stock price and market data analysis
* Technical trend analysis
* Risk analysis
* Performance analysis
* Trade Setup Report 

## 🛠️ Built With

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* yfinance

## 📌 Disclaimer
FinanceFlight is intended for educational and informational purposes only. The analysis and signals provided by the application should not be considered financial advice or a recommendation to buy or sell any security.
